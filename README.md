# Omnexa Wash - Interactive Frontend Demo 🚗✨
### ديمو تفاعلي احترافي لخدمة غسيل السيارات المتنقل والمغاسل الشريكة (السوق السعودي)

---

## 🌟 نظرة عامة
تم تصميم وبناء هذا الـ **Demo** التفاعلي المتكامل لمشروع **Omnexa Wash** وفق أعلى معايير تجربة المستخدم (UX/UI) مع استلهام أسلوب وهيكل الموقع المرجعي العالمي وتطويره بهوية بصرية مستقلة بالكامل خاصة بعلامة **Omnexa** ومخصصة للسوق السعودي (الريال السعودي SAR، ضريبة 15%، أحياء الرياض وجدة، والدفع عبر مدى و Apple Pay).

---

## 🚀 كيفية تشغيل وتجربة الديمو
لا يتطلب المشروع أي خادم خارجي أو تثبيت حزم أو إعدادات مسبقة؛ يمكنك فتحه وتشغيله فوراً:

1. افتح الملف الرئيسي:
   ```
   index.html
   ```
   مباشرة في أي متصفح ويب حديث (Google Chrome، Microsoft Edge، Safari، أو على الجوال).
2. استمتع بتجربة كامل رحلة العميل من البداية وحتى إتمام وتتبع الغسيل!

---

## 📱 المزايا والوظائف الـ 12 المتضمنة في الديمو:

1. **نظام تسجيل الدخول والتبديل التجريبي (Demo Accounts):**
   - تبديل بضغطة زر بين 3 أدوار رئيسية من الشريط العلوي:
     - **العميل:** ماجد العتيبي (عضوية ذهبية VIP).
     - **الكابتن:** فهد الدوسري (شاحنة خدمة متنقلة مجهزة).
     - **الإدارة:** سارة المنصور (مديرة العمليات).
2. **تحديد موقع السيارة على الخريطة التفاعلية (Location Picker):**
   - خريطة تفاعلية (Leaflet.js) مجهزة لأحياء الرياض مع إمكانية سحب وإفلات الدبوس الأحمر لتحديد مكان وقوف السيارة بدقة.
3. **استعراض المغاسل والكباتن القريبة (Nearby Map & Vans):**
   - خريطة حية تعرض أماكن شاحنات الخدمة المتنقلة الفورية والمحطات الثابتة الشريكة مع تقييماتها ومسافة الوصول بالكيلومتر.
4. **باقات الخدمات والأسعار الشفافة:**
   - 4 باقات رئيسية متدرجة:
     - **غسيل إكسبريس ساطع** (45 ر.س / 30 دقيقة)
     - **غسيل أومنيسكا الشامل** (89 ر.س / 60 دقيقة - الأكثر طلباً)
     - **غسيل البخار المتطور والتعقيم** (149 ر.س / 85 دقيقة)
     - **تلميع صالة العرض ونانو سيراميك** (279 ر.س / 140 دقيقة)
   - 5 خدمات إضافية مخصصة (شمع نانو، حوض المحرك، إزالة شعر الحيوانات، تعقيم الأوزون، ترطيب مقاعد الجلد).
5. **اختيار نوع وفئة السيارة:**
   - سيدان (1.0x)، دفع رباعي عائلي (1.25x)، شاحنة وبيك أب (1.45x)، وفارهة رياضية (1.35x) مع تحديث السعر الفوري.
6. **اختيار الخدمة والإضافات وتحديث الفاتورة لحظياً:**
   - إمكانية تحديد وإلغاء الإضافات مع حساب المجموع التراخيضي لحظياً.
7. **تحديد الموعد والفترة الزمنية:**
   - خيار الخدمة الفورية السريعة (خلال 35-45 دقيقة) أو حجز موعد مجدول (صباحي / مسائي).
8. **مراجعة الحساب وكوبونات الخصم:**
   - تفقيط الحساب بدقة مع دعم كوبون الخصم التجريبي **`OMNEXA20`** (خصم 20%) مع احتساب ضريبة القيمة المضافة 15%.
9. **تأكيد الحجز والدفع التجريبي:**
   - محاكاة الدفع عبر مدى، Apple Pay، البطاقة الائتمانية، أو نقداً عند الخدمة، مع شاشة تأكيد احتفالية ورقم حجز فريد.
10. **صفحة تتبع حالة الطلب المباشرة (Live Tracking):**
    - خريطة حية مع سيارة الكابتن المتحركة تقترب تدريجياً من موقع العميل.
    - مؤشر مراحل الطلب (مؤكد -> تم التعيين -> بالطريق -> جاري الغسيل -> تم الإنجاز).
    - صور فحص الجودة التفاعلية (قبل وبعد الغسيل) مع سلايدر تفاعلي بالسحب.
    - محادثة حية مع الكابتن (Live In-App Chat) مع ردود تلقائية سريعة واتصال مباشر.
11. **سجل الطلبات السابقة وإعادة الطلب:**
    - استعراض الطلبات النشطة والمكتملة، زر إعادة الطلب بضغطة زر، عرض الفاتورة الضريبية للطباعة، وتقييم الكابتن.
12. **الملف الشخصي، بطاقة الولاء، وإدارة الأسطول (My Garage):**
    - بطاقة ولاء تفاعلية بنظام الختم (5 غسلات = غسيل شامل مجاني).
    - محفظة الرصيد وكود الدعوة.
    - إدارة سيارات العميل مع إمكانية إضافة سيارات جديدة بلوحاتها وألوانها.

## 🎨 مزايا التصميم والهوية البصرية:
- **دعم كامل للغة العربية (RTL)** مع إمكانية التبديل الفوري إلى **الإنجليزية (LTR)**.
- **محاكي شاشة الجوال المدمج (Mobile Device Simulator):** زر علوي يسمح لك بعرض التطبيق داخل إطار هاتف ذكي أنيق لاختبار تجربة تطبيق الجوال، أو التبديل لعرض الشاشة الكاملة.
- خطوط عربية حديثة وأيقونات متناسقة وألوان تعكس النظافة والثقة والتقنية (`Deep Navy` + `Sapphire Blue` + `Fresh Cyan Glow`).
